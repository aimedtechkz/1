# Grok Perfume Ad Generator

Генерация кинематографичной 10-секундной рекламы парфюма с помощью **Grok Imagine Video 1.5** (xAI) через Vercel AI SDK.

## Требования

- Node.js 18+
- API-ключ xAI → [console.x.ai](https://console.x.ai)

## Установка

```bash
git clone https://github.com/YOUR_USERNAME/grok-perfume-ad.git
cd grok-perfume-ad
npm install
