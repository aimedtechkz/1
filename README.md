# Grok Imagine Video — пример генерации видео

Простой пример генерации 10-секундного рекламного ролика парфюма с помощью **Grok Imagine Video 1.5** от xAI.

## Что делает этот скрипт

- Берёт референсное изображение флакона
- Генерирует кинематографичное 10-секундное видео в стиле люксовой рекламы
- Использует официальный AI SDK (`@ai-sdk/xai`)

## Требования

- Node.js 18+
- API-ключ от xAI [](https://console.x.ai)
